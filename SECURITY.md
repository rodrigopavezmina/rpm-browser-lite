# Seguridad y reporte responsable

RPM IA Job Apply Browser Lite Turbo utiliza un perfil local e independiente de Microsoft WebView2 para conservar sesiones de los sitios que el usuario abre. El proyecto no solicita claves API ni envía contraseñas a un servicio propio.

No incluyas en issues, pull requests ni commits:

- `estado.json` o cualquier archivo de `%LOCALAPPDATA%\RPM IA Job Apply Browser Lite Turbo`.
- Cookies, tokens de sesión, capturas o notas personales.
- Contraseñas, URLs privadas o datos de cuentas.

Para reportar una vulnerabilidad, abre un issue sin adjuntar datos sensibles y describe pasos reproducibles, versión de Windows y versión de RPM IA Job Apply Browser Lite Turbo.
